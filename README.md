# 안심길 앱 기능명세서 v2.0 (구현본)

- 작성일: 2026-10-08
- 대상: 바탕화면 `안심길_앱` 폴더의 웹앱(PWA) — 실제 구현 기준 명세
- 서비스 범위: 성남시 은행동 3개 구역(A 은행근린공원 일대 · B 남한산성시장 일대 · C 은행1동 언덕 골목), 장소 35곳 (직접 확인한 길과 이어진 곳만)
- 한 줄 정의: 계단·경사·인도 정보를 반영해 어르신에게 **덜 힘든 길**을 찾아 주는 도보 길안내 웹앱

## 1. 화면 구성과 흐름

```
S00 시작 안내(3단계) → 계단 설정 → S01 홈
S01 홈 ─┬─ 자주 가는 곳 탭 ───────────┐
        ├─ 최근 검색 탭 ──────────────┤
        └─ 도착 칸 → S02 장소 고르기 ─┤
                                      ↓
                               S03 길 찾는 중
                     ┌────────────────┼────────────────┐
                 경로 2개 이상      경로 1개         경로 0개
                     ↓                ↓                ↓
                S04 경로 결과(총 경로 N개 / 길 1개)    E03
                     ↓ [안내 시작]
                S07-1 안내 미리보기(경로 목록·높이 변화·출처)
                     ↓ [경로 시작]
                S07-2 단계별 안내 → 도착 → 홈
```

| 화면 | 역할 |
|---|---|
| S00 시작 안내 | 앱 소개 3장 + 계단 조건 설정(4단계째) |
| 설정 | 계단 조건, 돌아가는 정도, 글자 크기, 앱 소개 다시 보기, 홈 화면에 앱 추가하기 |
| S01 홈 | 출발·도착 칸, 구역 지도, 자주 가는 곳, 최근 검색 |
| S02 장소 고르기 | 장소 검색 |
| S03 길 찾는 중 | 출발→도착 표시, 취소 |
| S04 경로 결과 | 지도 + 경로 카드(최대 3개) |
| S07-1 안내 미리보기 | 경로 전체 지도, 단계 목록, 높이 변화, 정보 출처 |
| S07-2 단계별 안내 | 현재 단계 배너, 확대 지도, 이전/다음 안내 |
| E01~E04 | 같은 장소 / 위치 사용 불가 / 길 없음 / 연결 오류 |

## 2. 기능 상세

### F-01 시작 안내 `S00`

- 정의: 첫 실행 시 앱 목적과 데이터 근거를 3장으로 소개한 뒤 계단 조건을 고르는 단계
- 구성
  - ① 덜 힘든 길로 안내 (언덕길 일러스트)
  - ② 가까운 길이 편한 길은 아님 (실제 지도 위 짧은 길 vs 덜 힘든 길 비교, 계단 197단 표시)
  - ③ 골목마다 직접 걸어서 확인 (직접 조사한 길 3.0km·31개 구간, 직접 찍은 사진 76장)
  - ④ 계단 조건 선택 → [시작하기]
- 공통: 진행 점 4개, [건너뛰기], [이전]/[다음], 🔊 화면 읽어 주기
- 넘기기: 버튼 외에 화면을 밀어서(좌·우·위·아래 50px 이상) 또는 마우스 휠·트랙패드 스크롤로 다음/이전 이동 (연속 스크롤은 0.7초 간격으로 한 장씩)
- 다시 보기: 설정 → 도움말 → [앱 소개 다시 보기]

### F-02 걷기 설정

| 항목 | 내용 |
|---|---|
| 계단 조건 | 계단도 괜찮아요 / 계단은 어려워요(기본) — 손잡이 데이터가 없어 손잡이 조건은 제외 |
| 돌아가는 정도 | 조금만 돌아갈래요(1.3배, 기본) / 많이 돌아가도 괜찮아요(2배) — 인터뷰 Q6 |
| 글자 크기 | 5단계 직접 선택(작게 0.9 · 보통 1.0 · 크게 1.15 · 더 크게 1.3 · 아주 크게 1.45배) + 안내 문장 미리보기, 기기에 저장 |
| 앱 소개 다시 보기 | 도움말 항목, 시작 안내 4단계 다시 보기 |
| 앱 설치 | 설정 맨 아래 [홈 화면에 앱 추가하기] 항상 표시 · 안드로이드 크롬은 바로 설치 창 · 그 밖의 브라우저·아이폰은 누르면 추가 방법 안내 · 이미 설치돼 있으면 "홈 화면에 추가돼 있어요" |

- 진입: 홈 오른쪽 위 ☰ 버튼

### F-03 홈 `S01`

- 출발 칸(검정 점) · 도착 칸(초록 점)
- 구역 지도: 출발지 구역의 지도, 갈 수 있는 장소 점 표시, "갈 수 있는 곳 N곳"
- 자주 가는 곳 3개 타일: 많이 찾은 순(구역 안) + 부족하면 기본 장소로 채움, **탭 한 번으로 바로 길찾기**
- 최근 검색(최대 4개): 탭하면 바로 길찾기, [모두 지우기], 비었을 때 "최근 찾은 장소가 없어요"
- 최근 검색·찾은 횟수는 기기 안(localStorage)에만 저장

### F-04 장소 고르기 `S02`

- 장소 35곳(정류장·약국·시장·공공기관·공원·가게 등) 이름 검색
- **말로 찾기**: 검색칸 오른쪽 🎤 버튼 → 장소 이름을 말하면(예: "은행시장 가줘") 자동으로 경로 화면으로 이동
  - Web Speech API 한국어 인식, "가줘·까지·로" 같은 말끝은 떼고 비교, 글자 조각(2글자 단위) 유사도 0.6 이상이면 바로 선택
  - 있는 장소지만 출발지와 확인된 길로 이어지지 않으면 "아직 확인한 길로 갈 수 없어요" 안내
  - 비슷한 장소가 없으면 "못 찾았어요" + 들은 말 표시, 직접 고르기 유도
  - 음성 인식을 지원하지 않는 브라우저에서는 "글자로 검색해 주세요" 안내, 마이크 권한이 꺼져 있으면 허용 방법 안내
- 도착지 목록에는 출발지와 **직접 확인한 길로 이어진 장소만** 표시 (홈 지도 점·자주 가는 곳·최근 검색도 같은 기준)
- 출발지 고르기: 3개 구역 전체 목록 (현재 위치 사용은 서비스 범위가 은행동뿐이라 v2.0에서 제외)
- 도착지 고르기: 출발지와 같은 구역 장소만 표시 (구역 간 길 데이터 미연결)
- 장소 선택 즉시 길찾기 시작

### F-05 길 찾는 중 `S03`

- "길을 찾고 있어요" + 출발→도착 이름, [취소] → 홈
- 연속 탭 시 중복 탐색 방지
- 결과 0개 → E03

### F-06 경로 결과 `S04`

- 상단: 출발·도착 카드(출발 회색 / 도착 초록·굵게)
- 지도
  - 선택한 경로: 초록 굵은 실선 + "덜 힘든 길" 꼬리표
  - 나머지 경로: 회색 점선 + 위험 뱃지(계단 197단, 가파른 언덕 등)가 공중에 표시
- 제목: "총 경로 N개" (1개면 "안내할 수 있는 길이 1개예요")
- 경로 카드(테두리로 구분, 선택 시 초록 테두리)
  - 경로 1 / 2 / 3 + 선 모양 표시(실선·점선), 경로 1에 `추천`
  - 큰 시간(분) · 도착 예정 시각 · 거리 · **꺾는 곳 N번**
  - 시간 비교 한 줄: "3분 더 걸리지만 계단 197단을 피해요" / "3분 빠르지만 계단 197단이 있어요" / "가장 빠른 길이 가장 편한 길이에요"
  - 선택한 카드: 작은 높이 그래프 + "오르막 +Nm · 내리막 Nm"
  - 뱃지: `✓ 계단 197단 피함` / `계단 51단` `차와 같이 걷는 길` 등 최대 2개
  - 돌아가는 정도 뱃지: 가장 빠른 길 대비 1.3~1.5배 `조금 돌아가요`, 1.5배 초과 `많이 돌아가요 · N배`
  - 계단 어려움 설정에서 상한을 넘어야만 계단을 피할 수 있으면 아래에 "계단을 피하려면 가장 빠른 길보다 N배 돌아가야 해요"
- 하단: [안내 시작]

### F-07 안내 미리보기 `S07-1`

- 경로 전체가 한 화면에 들어오도록 지도 확대, 출발점·도착 핀·위험 아이콘 표시
- 하단 시트(올리기/내리기)
  - 단계 목록(카카오맵형): ↑ 출발 / ↰↱ 회전 안내 / 📍 도착
  - 회전 안내는 주변 장소 기준: "태평양약국 앞에서 왼쪽으로 도세요" → 장소가 없으면 "오른쪽으로 돌아 은행로41번길 쪽으로 가세요" → 둘 다 없으면 "왼쪽으로 도세요"
  - 기준 장소: 회전 지점 30m 안의 가게·시설·정류장·이름 있는 건물·공원(OpenStreetMap), 같은 장소 연속 사용 금지
  - 지도 위에 기준 장소 이름표 표시
  - 각 단계: 이동 거리 + 그 구간 주의 정보(초록 글씨)
  - 정보 출처(현장 조사 2026.10.04) — 높이 변화 그래프는 경로 결과(F-06) 카드에만 표시
- 하단 버튼: 🔊 길 요약 듣기 · [경로 시작]

### F-08 단계별 안내 `S07-2`

- 위쪽 초록 배너: 현재 단계 아이콘 + "은행오거리 쉼터 앞에서 왼쪽으로 도세요 / 37m 이동 · 신호 고장 횡단보도"
- 지도: 현재 단계 지점으로 확대, 초록 링 + 기준 장소 이름표 강조
- 하단: 남은 시간·도착 시각, "그다음 ○○", [이전] · [다음 안내] (마지막은 [안내 마치기] → 홈)
- 단계마다 음성 안내 ("은행오거리 쉼터 앞에서 왼쪽으로 도세요. 37미터 이동하세요. 주의할 곳은 계단 197단, 어두운 길이에요.")
- 실제 GPS 위치 추적은 미구현(버튼으로 단계 이동)

### F-09 사진으로 길 알리기 (AI + 사람 확인) `S07-3`

- 길 안내 중 지도 왼쪽 아래 **[📷 이 길 사진으로 알리기]** → 지금 안내 중인 구간에 대한 제보 화면
- [사진 찍기](카메라) 또는 [앨범에서 고르기]
- AI(2차 학습 모델, 휴대폰 안에서 실행)가 사진 속 계단 영역을 주황색으로 칠하고 먼저 판단
  - 계단 면적 3% 이상 → "계단이 있는 것 같아요" / 미만 → "계단은 보이지 않아요" (현장 사진 기준: 계단 사진 11~27%, 계단 없는 사진 0.4% 이하)
- 사람이 최종 확인: [맞아요] / [아니에요] → **사람이 고른 답만 저장**
- '계단 있음'으로 확인된 구간 → 다음 길찾기부터 계단으로 계산 (지도·경로 카드에 "계단 (주민 제보)" 표시, 지금 안내 중인 경로는 그대로)
- AI 파일을 못 불러오면 사진만 보고 직접 [계단이 있어요 / 계단 없어요] 선택
- 설정 > **내가 알린 길**: 제보 목록(장소·결과·AI 판단과 같았는지·날짜), [지우기]로 되돌리기
- 기술
  - 모델: DeepLabV3+ ResNet-50 → ONNX 변환 + 8비트 양자화(약 27MB), `assets/ai/stairs_v2.onnx`
  - 실행: onnxruntime-web 1.22.0 (WebAssembly), 사진 긴 변 448px, 한 장에 약 3~8초
  - AI 파일(약 40MB)은 제보 기능을 처음 쓸 때만 내려받고 이후 기기에 저장
- 한계: 계단만 판단(인도·골목 구분은 현장 사진에서 정확도 부족), 제보는 이 기기 안에만 저장(서버 없음)

### F-10 음성 안내

- Web Speech API, 기기의 한국어 음성 중 가장 자연스러운 음성 자동 선택(Edge의 Natural 음성 우선)
- 시작 안내 읽기, 길 요약 듣기, 단계별 안내

### F-11 예외 화면 `E01~E04`

| 코드 | 상황 | 문구 | 복구 |
|---|---|---|---|
| E01 | 출발=도착 | 출발지와 목적지가 같아요 | 목적지 다시 고르기(출발지 유지) |
| E02 | 위치 사용 불가 | 내 위치를 쓸 수 없어요 | 출발지 직접 고르기 / 다시 시도 |
| E03 | 경로 0개·다른 구역 | 안내할 수 있는 길이 없어요 | 장소 바꾸기 |
| E04 | 연결 오류 | 길 찾기에 실패했어요 | 다시 시도 / 장소 바꾸기 |

### F-12 지도 확대·이동 (홈 · 경로 결과 · 길 안내 공통)

- 손가락 두 개로 벌리기·오므리기, 한 손가락 끌기, PC는 마우스 휠
- 지도 오른쪽 [+]·[−] 버튼(어르신용 큰 버튼), 움직인 뒤에는 [⌖ 처음 위치로] 버튼 표시
- 이동 범위: 데이터가 있는 성남 은행동 일대(건물 범위 + 120m)로 제한, 확대 최대 5배(길 안내 8배)
- 확대해도 경로선 굵기·뱃지 크기 유지, 화면 전환·경로 변경·안내 단계 이동 시 원래 위치로 복귀

### 3.1-1 공공데이터 (성남시 교통신호기 시설물현황, 2026.06.11)

- 횡단보도 안내에 신호등 설비 정보 추가: "음성 안내·남은 시간 표시 신호등 설치"
- 좌표가 없는 주소·교차로 이름 자료라, 조사 구간과 이름·위치로 확실히 맞는 곳만 반영
  - 반영: A08 ↔ 유할인마트 사거리(은행로 42) — 보행등 8 · 음향신호기 6 · 잔여시간 표시 8
- 신호 고장 여부는 공공데이터에 없어 현장조사 값 유지 (A08은 현장조사 당시 고장)
- 이 교차로를 지나는 경로 28개에서 표시
- 은행동 일대 신호기 자료 약 22곳 중 나머지는 조사 구간 밖(산성대로·자혜로 큰길 등)이거나 위치 확인 필요
- 같은 시 공공데이터 중 적치물 등 장애물(982건)·보행자 전용도로(279건)는 은행동 일대 0건 → 미반영

### 3.1-2 B 구역 현장 메모 반영 (조사자 메모, 2026.10.04)

| 구간 | 메모 | 반영 |
|---|---|---|
| B01 | 횡단보도 4개 중 1개 신호 없음, 경사 1.7~8.5° | 신호 있음 3 · 없음 1로 나눠 계산 |
| B03 | 아파트 입구 계단 10여 개는 옆 오르막으로 피할 수 있음, 인도·차도 구분 거의 없음 | 계단 없음 · 차와 같이 걷는 길 |
| B04 | 무지개 계단 51단(옆 계단 약 97단은 경로 아님), 횡단보도 0, 경사 10° 넘는 곳 많음, 울퉁불퉁 | 계단 51단 · 노면 불량 |
| B06 | 비교적 순탄한 내리막, 쓰레기·음식물 쓰레기 많음 | "쓰레기가 많은 길" 안내 + 작은 부담(길이 × 0.1) |
| B07 | 올라온 길을 내려가며 경사만 측정, 횡단보도 1 | 걸은 방향 기준 내리막 |

- B06·B07은 아직 장소와 이어지지 않아 경로에는 나오지 않음 (B05·B10·B11 조사 후 연결)

### 3.2 간선 비용 (방향별)

```
비용 = 길이 × 경사계수(Tobler) + 계단 부담 + 횡단보도 부담 + 길이 × (인도 + 노면 + 조명)
```

| 항목 | 값 |
|---|---|
| 경사계수 | Tobler 보행속도 함수 (오르막·내리막 다르게) |
| 계단 부담 | 길이 × 계단 배수 (계단도 괜찮아요 0.5 · 계단은 어려워요 30) |
| 횡단보도 | 신호 있음 30 · 없음/고장 60 (개당) |
| 인도 | 있음 0 · 부분 0.35 · 없음 0.8 (좁은 차길 부담 상향 — 인터뷰 Q1) |
| 꺾는 곳 | 갈림길에서 40° 이상 꺾을 때마다 35 (찾기 쉬운 길 — 인터뷰 Q3) |
| 노면 | 양호 0 · 불량 0.3 |
| 조명 | 양호 0 · 어두움 0.15 |
| 혼합 경사 구간 | 양방향 모두 오르막으로 계산 |

### 3.3 후보 경로 만들기

- 경로 1: 위 비용이 가장 낮은 길 (Dijkstra, 지점 + 들어온 길 상태로 탐색해 꺾는 횟수 반영)
- 돌아가는 정도 상한(인터뷰 Q6): 경로 1이 가장 짧은 길의 1.3배(설정 시 2배)를 넘으면, 상한 안에서 비용이 가장 낮은 길을 다시 찾아 추천
  - 원래 경로 1은 "더 편하지만 많이 돌아가는 길"로 함께 표시
  - 단, 계단 어려움 설정에서 상한 안의 길이 계단을 더 지나가면 원래 길 유지 + 안내 문구
- 짧은 길: 거리만으로 가장 짧은 길 (경로 1과 다를 때만)
- 다른 길: 이미 찾은 길에 벌점(×4, ×8 …)을 주며 다시 탐색
- 중복 제거: 다른 경로와 겹치지 않는 부분이 25m 미만이면 제외
- 길이 제한: 경로 1의 2배 또는 +300m 이내 (다른 길 탐색 시)
- 최대 3개

### 3.4 표시 값

- 예상 시간 (v2.0): 구간마다 걷는 시간을 더해 계산
  - 평지: 어르신 걸음 분당 50m(초속 약 0.8m)
  - 경사: Tobler 보행속도 공식으로 오르막·가파른 내리막일수록 느리게
  - 계단: 단당 1.2초 (계단 구간은 경사 계산과 비교해 더 긴 쪽)
  - 횡단보도 대기: 신호 있음 20초 · 고장 10초 · 신호 없음 5초 (개당)
  - 결과: 조사한 길 전체 평균 실제 이동 속도 약 분당 40m
  - 예: 은행근린공원 서쪽입구 → 구현진약국 앞 정류장 — 계단 197단 짧은 길 12분 / 덜 힘든 길 12분 ("시간 차이 없이 계단 197단을 피해요")
  - 길 안내 중 남은 시간도 같은 방식으로 계산
- 도착 시각: 현재 시각 + 예상 시간
- 회전 안내: 경로 선이 40° 이상 꺾이는 지점, 14m 이내 회전은 하나로 합침
- 높이 변화: 구간 길이 × tan(경사도 평균) 누적, 출발 기준 상대 높이
  - 혼합 경사는 가운데가 볼록한 언덕으로 근사
  - B03·B06·B07 경사(현장 측정, 10.11 반영): B03 평균 7.2°(4회, 오르막) · B06 6.7°(내리막) · B07 평균 8.8°(3회, 걸은 방향 기준 내리막)
  - 경사를 재지 못한 구간이 생기면 그래프에서 비움
